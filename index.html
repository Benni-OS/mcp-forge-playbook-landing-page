The Tool

What is mcp-forge?

mcp-forge is a FastAPI-style framework for building MCP servers in Python. You define tools with a decorator. Pydantic validates inputs automatically. Transports are one flag away.

# Install pip install mcp-forge # Build your first tool in 10 lines from mcp_forge import ForgeApp from pydantic import BaseModel app = ForgeApp("my-operator-server") class SearchInput(BaseModel): query: str limit: int = 10 @app.tool() async def search(input: SearchInput) -> dict: # your logic here return {"results": []}

That's it. mcp-forge generates the JSON schema, validates the input, handles the transport, and exposes the tool to any MCP-compatible AI client — Claude, Cursor, VS Code, AutoGen, CrewAI.
